# AURORA XER Insight Free

Portable browser-based Primavera P6 XER schedule analysis toolkit.

## Current Package

- AURORA XER Insight Free v0.4
- Read-only HTML/JavaScript tool
- No installation required
- Runs locally in the browser
- No server upload required

## Run

Open the application file:

[AURORA XER Insight Free v0.4](AURORA_XER_Insight_Free_v0_4/index.html)

Or open this file manually in Chrome or Edge:

AURORA_XER_Insight_Free_v0_4/index.html

## Main Features

- XER schedule viewer
- Executive dashboard
- Executive summary
- DCMA 14-Point Advanced Lite
- Advanced S-Curve Lite / EVM readiness
- Schedule quality checks
- Logic network analysis
- Constraints / float / criticality / milestones
- Activity codes explorer
- UDF explorer
- Resource / assignment / cost summaries
- Auto risk register
- Period reporting
- Two-XER comparison
- Data dictionary / raw XER table viewer
- CSV export
- HTML report export

## Important

This free version is read-only. It does not modify XER files and does not generate P6-importable XER files.

## Recommended Use

1. Export a `.xer` file from Primavera P6.
2. Open `AURORA_XER_Insight_Free_v0_4/index.html` in Chrome or Edge.
3. Load the XER file.
4. Review dashboard, DCMA Lite, S-Curve Lite, schedule quality, logic, codes, UDFs, resources and raw tables.
5. Export CSV or HTML report if needed.
