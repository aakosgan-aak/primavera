# AURORA XER Insight Free

Portable browser-based Primavera P6 XER schedule analysis toolkit.

## Current package

- AURORA XER Insight Free v0.4
- Read-only HTML/JavaScript tool
- No installation required
- Open `AURORA_XER_Insight_Free_v0_4/AURORA_XER_Insight_Free_v0_4.html` in Chrome or Edge

## Main features

- XER schedule viewer
- Executive dashboard
- Executive summary
- DCMA 14-Point Advanced Lite
- Advanced S-Curve Lite / EVM readiness
- Schedule quality checks
- Logic network analysis
- Constraints / float / criticality / milestones
- Activity codes explorer
- UDF explorer
- Resource / assignment / cost summaries
- Auto risk register
- Period reporting
- Two-XER comparison
- Data dictionary / raw table viewer
- CSV and HTML report export

## Important

This free version is read-only. It does not modify XER files and does not generate P6-importable XER files.

Premium AURORA P6 Suite features should remain separate:

- XER writer / importable XER validator
- P6 API integration
- OPC REST integration
- SYNCHRO 4D automation
- Power BI model automation
- Full time-phased PV / EV / AC engine
